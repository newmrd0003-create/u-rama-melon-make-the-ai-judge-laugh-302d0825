## Entry

`main.py` deterministically writes one one-line office joke to
`/output/entry.txt`:

> We've been circling back on the same decision for six months — the circle now has its own parking space.

104 characters, one line — a true office observation (the decision that
gets "circled back" forever) with the twist landing on the last words.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt`. Running it twice produces byte-identical output.
